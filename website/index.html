手机和 Mac 连接同一局域网。
接收端使用 Mac 自带的文件共享。

1

让 Mac 准备好接收

在系统设置中打开「文件共享」，启用 SMB，添加接收文件夹，并为自己的账户设置读写权限。

Mac → 系统设置 → 共享
2

在手机里连接一次

填写 Mac 的局域网地址、共享名称、用户名和密码。密码默认隐藏，并加密保存在手机本地。

SMB 分享 → 连接设置
3

选文件，然后分享

在文件管理器或相册里选中文件，点分享，再选「SMB 分享」。大文件会打开进度页，请保持前台、不要锁屏；完成后会收到通知。

文件 → 分享 → SMB 分享

你可能想问

用之前，
再了解一点。

Mac 上需要安装什么吗？+

不需要额外客户端。使用 macOS 自带的文件共享，在共享选项中启用 SMB，并开放你希望接收文件的文件夹。

为什么请求通知权限？+

通知用于展示传输状态和完成结果。小文件可等待通知；大文件请保持进度页在前台。App 仅访问你选择并授权分享的文件。

文件会上传到你们的服务器吗？+

不会。文件由手机通过 SMB 发往你配置的服务器。SMB Share 没有文件中转服务，也没有分析 SDK。请只连接你信任的网络和 SMB 服务器。

能连接 NAS 或 Windows 吗？+

底层使用 SMB2/3 协议。当前实际验证以 Mac 为主，NAS、Windows 和其他服务器的完整兼容性尚未验证；不支持 SMB1 和域账户配置。

大文件中断了怎么办？+

部分手机会冻结后台传输，当前版本不提供断点续传。请检查接收目录和失败通知，再重新分享；残留的 .smbshare-*.part 是未完成的临时文件，不代表传输成功。

如何反馈问题或参与改进？+

欢迎在 GitHub Issues 描述手机型号、Android 版本、文件大小和复现步骤。请不要附上密码、密钥或未经处理的个人截图。
